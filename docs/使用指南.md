# claude-damn 全功能清单与快速上手指南

> 面向 Windows 用户的完整操作手册：涵盖从首次安装、日常防泄守护、多账号切换、维护排障到命令行自动化的全部功能。

---

## 一、三分钟快速上手（新手 5 步）

1. **开启代理客户端的 TUN 模式**
   - 先运行 Clash Verge / FlClash / sing-box / WireGuard 等代理客户端，确保虚拟 TUN 网卡在线且节点为非 `CN` 出口。
2. **安装并启动 `claude-damn`**
   - 从 [GitHub Releases](https://github.com/zxl3305479573-max/claude-damn/releases) 解压后运行 `ClaudeDesktopGuardian.App.exe`，或在源码目录用**管理员 PowerShell** 执行 `.\install.ps1`（默认安装到 `D:\Apps\claude-damn` 并注册开机任务与桌面快捷方式）。
   - 首次启动弹出系统管理员权限（UAC）提示时点 **「是」**，以拉起后台管理员助手（`ClaudeDesktopGuardian.Helper.exe`）。
3. **等待首轮体检完成**
   - 打开 **「环境监控」** 页，等待顶部状态徽章变为绿色正常；若出现非 VPN 网卡 IPv6 旁路、时区不一致或 Clash 规则未置顶，切到 **「维护工具」** 点击 **「一键修复环境」**。
4. **通过「安全启动 Claude」打开客户端**
   - 点击窗口底部或托盘菜单中的 **「安全启动 Claude」**。程序会校验全部硬检查通过，并自动传入 `--no-proxy-server` 让 Claude Desktop 绕过系统代理、仅经由 TUN 通信。
   - **不要**直接双击原来的 Claude 桌面快捷方式，否则不会带该参数，开启严格 WFP 时也会被拦截。
5. **正确隐藏与彻底退出**
   - 点击右上角 `×` 会最小化到系统托盘，后台持续守护。
   - 需要彻底关闭时，**右键系统托盘图标 → 选择「退出并恢复时区与网络策略」**，程序会自动恢复原 Windows 时区、清理防火墙规则并移除 WFP 出站锁。

## 二、全局界面与常驻入口清单

### 1. 顶部状态栏
| 控件 / 区域 | 作用说明 |
| :--- | :--- |
| **版本与更新提示** | 启动时自动只读检查 GitHub 正式 Release，显示当前是否最新或可升级版本。 |
| **`检查更新` 按钮** | 手动触发检查；发现新版时变为 `更新到 vX.Y.Z`，点击后自动下载、校验 SHA-256、请求 UAC 并安全替换（失败自动回滚，不覆盖账号数据）。 |
| **WFP 状态徽章** | 实时显示内核级 TUN-only 出站锁状态（未启用 / 生效中 / 过期 / 不可用）。 |
| **总体防护徽章** | 一眼识别当前安全态（检查中 / 正常守护 / 存在警告 / 已阻断锁定）。 |

### 2. 顶部 4 张实时 KPI 卡片
- **VPN / TUN 网卡**：当前识别到的虚拟网卡名与代理客户端在线状态。
- **IPv4 & IPv6 出口**：出口 IP、国家地区（开启系统代理时同时展示代理路径与直连 TUN 路径一致性）以及 IPv6 出口状态。
- **DNS & 路由**：隧道 DNS 与 `claude.ai` 解析状态（是否命中 Fake-IP `198.18.*`）。
- **Claude 进程与账号**：当前用户运行中的 Claude Desktop 进程数与当前绑定的账号槽位（`A`–`D`）。

### 3. 底部全局操作栏
| 控件 | 作用说明 |
| :--- | :--- |
| **`忽略 WebRTC 未验证`** | 仅忽略 WebRTC 处于「未验证（Unknown）」状态时的干扰，检测结果仍保留显示；**一旦确认真实非 VPN 公网 IP 泄露仍会强制阻断**。 |
| **`安全启动 Claude`** | 仅在未阻断且全部硬检查通过时启动 Claude Desktop（兼容传统 EXE 与 MSIX），自动绕过系统代理走 TUN。 |
| **`立即完整检查`** | 立刻触发一轮完整 24 项检查（含 DNS、IPv6、WebRTC、ASN、HTTPS、Clash 规则与信誉检测）。 |
| **`检查并解除阻断`** | 触发 Fail-Closed 红灯阻断锁定后，先修复代理/TUN，再点此按钮完成复检；所有阻断项归零后解除锁定与防火墙封锁。 |

### 4. 系统托盘与右下角小窗
- **双击托盘图标** / 右键 **`打开面板`**：呼出主窗口（程序内置单实例防双开，重复双击快捷方式也会直接唤起当前窗口）。
- 右键 **`安全启动 Claude`**：不打开主界面也能直接安全启动 Claude。
- 右键 **`保留右下角小窗口`**：开启/关闭桌面右下角置顶悬浮小窗（可左键按住拖动），实时展示防护状态、出口、网卡、WFP 状态、当前账号槽位与最后检查时间，并提供 **`打开面板`** 按钮。
- 右键 **`退出并恢复时区与网络策略`**：安全停止巡检、恢复系统原时区、清理本程序托管防火墙与 WFP 规则后退出。

## 三、四大标签页功能全清单

### Tab 1：环境监控

#### 左侧：24 项环境检查矩阵
默认每 **5 秒** 轻量巡检、每 **30 分钟** 完整体检，网络变化自动全检，出口基线最多 **60 秒** 刷新。每行右侧均有 **`复检`** 按钮，可单独重测该项与最小依赖。

- **核心硬检查（9 项，永不可关闭或降级；异常会触发 Fail-Closed 阻断并急停 Claude）**
  1. `proxy-client` **代理客户端**：目标或自动识别客户端在线；离线立即跳过所有外网探针。
  2. `vpn-adapter` **VPN/TUN 网卡**：虚拟网卡 `Up` 且持有有效非 APIPA IPv4；离线立即跳过外网探针。
  3. `default-route` **目标最佳路由**：校验具体探测目标与 Claude 活动连接最佳路由均走 TUN（兼容拆分默认路由、拦截更具体物理旁路；自动排除回环/私网/链路本地连接并保留 `198.18.*` 与公网目标，TUN 仅配 ULA IPv6 时不会误判阻断）。
  4. `egress-ip` **出口 IP**：拒绝 `CN`、匹配目标国家/IP，开启系统代理时强制核对代理路径与 TUN 直连路径一致。
  5. `ipv6` **IPv6 出口**：非 VPN 网卡无 `::/0`、`2000::/3`、`64:ff9b::/96` 路由；存在公网 IPv6 时须与 IPv4 同国。
  6. `helper-service` **管理员助手**：受限命名管道在线且响应正常（支持并发状态查询）。
  7. `firewall-readiness` **防火墙保护**：`BFE`/`MpsSvc` 正常、活动配置启用、本地策略未被组策略覆盖且规则可读。
  8. `wfp-policy` **WFP 内核出站锁**：开启「WFP 严格模式」后须为 `active`（否则阻断）；支持 TUN 网卡断开重连后自动重绑，并修复 junction 路径重复导致的 `stale` 误报。
  9. `tcp-only-policy` **Claude TCP-only**：开启后验证专用组对当前用户 Claude EXE/MSIX 全部出站 UDP 阻断生效（默认关闭显示 `已跳过`）。
- **进程与连接策略（2 项）**
  10. `claude-process` **Claude 进程树**：识别当前用户 Claude Desktop 进程（未运行仅提示，不阻断）。
  11. `active-connections` **活动连接**：读取双栈 TCP/UDP；放行 TCP `443` 与本机回环，非 443 远端端口告警，读取失败阻断。
- **可选与可插拔检查（13 项，可在设置页按项关闭为 `已跳过`，或开启非关键失败降级为警告）**
  12. `ip-consistency` **出口 IP 稳定性**：48 小时内不同出口数漂移监控（`iphistory.log`）。
  13. `timezone` **时区一致性**：与出口 IANA 时区自动同步，退出/卸载自动还原原时区。
  14. `locale` **系统地区 Locale**：检查 Windows 当前区域格式是否与目标国家匹配。
  15. `dns` **DNS 解析**：验证真实 `claude.ai` DNS 解析与 Fake-IP（`198.18.*`）特征。
  16. `webrtc` **WebRTC 泄露**：原生 4 组 STUN UDP + 内置 WebView2 浏览器 ICE 双层检测（支持 `proxy` / `reject`；**确认非 VPN 公网泄露永不降级**）。
  17. `clash-rules` **Clash 置顶路由**：Rule 模式下审计内核前 16 条置顶规则（13 Claude 域名 + 3 UDP STUN 端口）。
  18. `client-language` **Claude 客户端语言**：检查 Claude `config.json` 中的 `locale` 语言前缀。
  19. `asn` **ASN 网络类型**：通过 `ipinfo.io` + `PeeringDB` 识别住宅家宽（`Cable/DSL/ISP`）或机房属性。
  20. `claude-domains` **Claude HTTPS**：探测 Claude/Anthropic 生态 HTTPS 可达性（`2xx`/`3xx` 正常，预期 API `401` 需认证，`403`/`429` 警告）。
  21. `ip-rep-score` **IP 纯净度**（可插拔）：自定义 HTTPS 信誉源风险分低于阈值。
  22. `ip-rep-proxy` **IP 代理标记**（可插拔）：公开代理 / VPN / Tor 命中检测。
  23. `ip-rep-hosting` **IP 机房属性**（可插拔）：机房/数据中心标记检测。
  24. `ip-rep-blacklist` **IP 黑名单**（可插拔）：黑名单/滥用计数检测。

#### 右侧：实时证据与内核策略
- **WFP 快捷控制**：`启用 / 刷新 WFP`、`移除 WFP`、`启动 / 重连助手`。
- **选中检查项详情 & Evidence**：点击左侧任意一行，右侧实时显示完整说明、观测时间、缓存状态与结构化 `Evidence`，支持一键 **`复制`** 用于排查。
- **实时观测面板**：同屏展示 WebRTC STUN & 浏览器 ICE 候选、Claude 活动 TCP 连接、出口/系统时区与 Locale，以及最近一次断网/阻断原因。

### Tab 2：多账号管理

| 模块 | 功能与使用要点 |
| :--- | :--- |
| **`A–D` 账号隔离槽位** | 支持最多 4 个独立 Claude Desktop 账号数据目录（存于 `%LOCALAPPDATA%\ClaudeDesktopGuardian\accounts`）。<br>• **首次切换**：自动把你当前正在用的 Claude 数据归档到 **槽位 A**，不会丢数据。<br>• **Fail-Closed 事务保障**：点击 `切换到 A/B/C/D` 后先执行完整安全复检（阻断或环境不健康时拒绝切换），自动等待当前用户全部 Claude Desktop 与 Claude Code CLI 退出（超时中止），采用 `.new`/`.previous` 原子换位、失败自动回滚，切完自动以 `--no-proxy-server` 启动新账号。<br>• **`刷新槽位`**：立即刷新各槽位占用状态与最后保存时间。 |
| **加密快照迁移（`.csnap`）** | 采用 `CSNAP001` 格式（PBKDF2-HMAC-SHA256 20万次 + AES-256-CBC + HMAC-SHA256 认证加密 + 防 Zip-Slip 校验），与 `claude-switcher` 二进制互通。<br>• **`导出 .csnap 快照`**：选非活跃槽位、输入至少 8 位密码即可加密导出备份/换机。<br>• **`导入 .csnap 快照`**：选**空槽位**并输入解密密码导入。<br>• 操作结束后密码框自动清空内存。 |
| **跨账号保留路径** | 对应 `keep-in-workspace.txt` + **`保存清单`**。每行写一个 Claude 数据目录内的相对路径（如 `claude_desktop_config.json`），切号时自动保留共享（适合让 MCP 配置跨账号共用）；支持 `#` 注释，自动拦截绝对路径、`..` 与符号链接。 |

| **`Clash 规则状态`** | 只读审计 Clash Verge / FlClash 当前运行模式、控制端口与前 18 条内核实际生效规则。 |

| **`设备指纹体检`** | 只读检查中文字体、GPU、屏幕分辨率与虚拟化特征。 |

#### 2. 两个内置专项工具
- **一次性安全隔离浏览器**：填入任意 `http(s)://` 网址（默认 `https://browserleaks.com/webrtc`）点 **`安全打开`**，以禁用扩展与禁用非代理 UDP（`--force-webrtc-ip-handling-policy=disable_non_proxied_udp`）模式拉起独立临时浏览器窗口，关闭即销毁临时配置目录。
- **独立代理传输诊断**：填入代理 URL（支持 `http://`、`https://`、`socks5://`、`socks5h://`，须含端口）或点击 **`选配置…`** 选择含 `proxy_url` 的私有 JSON 文件，点 **`运行诊断`** 独立探测 `api.anthropic.com` 与 `claude.ai` 传输连通性——**不修改系统设置、不写客户端日志、不触碰账号状态**。
- 底部 **维护与诊断输出** 文本框支持滚动查看与 **`清空输出`**。

### Tab 4：检查与防护设置

#### 1. 基础网络与代理参数（左侧）
| 参数 | 说明与建议 |
| :--- | :--- |
| **代理客户端模式** | 默认 `auto` 自动识别；也可指定 `Clash Verge`、`FlClash`、`sing-box`、`ClashX`、`Surge`、`WireGuard`、`其他 TUN`。 |
| **期望出口国家 (两位)** | 如 `US`、`JP`、`SG`；留空表示只要非 `CN` 即放行。 |
| **期望出口 IP (可选)** | 固定独享 IP 用户可填写以防串线；动态节点留空即可。 |
| **期望地区 Locale** | 如 `en-US`、`ja-JP`；留空按出口国家自动推断。 |
| **VPN 网卡关键词** | 特殊虚拟网卡未被自动识别时填写关键词；通常留空。 |
| **FlClash 控制端口** | 留空或 `auto` 自动探测；仅允许本机回环地址（如 `9090` 或 `127.0.0.1:9090`）。 |
| **Clash 置顶代理组** | 点 **`自动识别`** 可自动读取 Clash 配置首个 `select` 代理组。 |
| **WebRTC 规则策略** | `proxy`（STUN UDP 走代理组，默认）或 `reject`（拒绝 UDP `3478`/`5349`/`19302`）。 |
| **轮询间隔 (轻秒 / 完分)** | 轻量巡检间隔（`2–60` 秒，默认 `5`）/ 完整检查间隔（`1–180` 分钟，默认 `30`）。 |

#### 2. 双层防护与日志策略（右上）
- **启用 WFP 内核级 TUN-only 出站锁（严格模式）**：推荐开启。在内核层锁死 Claude 仅允许经由指定 TUN 网卡出站，未生效即视为阻断。
- **WFP 允许本机回环通信（`127.0.0.1` / `::1`）**：需要与本机 MCP Server 通信时按需开启；若希望严格禁止 Claude 连接本机 HTTP 代理（系统代理留给 Codex 等其他软件用），请保持**关闭**。
- **Claude TCP-only（默认关闭）**：独立防火墙策略，阻断 Claude 全部出站 UDP（不影响代理内核）；可能影响语音/视频等实时功能，开启后须验证规则生效方允许启动。
- **非关键检查失败降级为警告**：开启后，可选检查失败不会触发阻断（核心硬检查与确认 WebRTC 泄露永远不会降级）。
- **启用脱敏运行日志**：写入 `%LOCALAPPDATA%\ClaudeDesktopGuardian\logs\guardian.log`（512 KiB 自动轮转，仅记录脱敏状态摘要）。

#### 3. 可插拔 IP 信誉源（右下）
- **数据源 URL**：仅接受 `https://`，支持 `{ip}` 占位符。新安装默认预填免注册免 Key 的 `https://api.ipquery.io/{ip}`（自动覆盖纯净度、代理标记与机房属性）；清空并保存即可关闭，或替换为自定义信誉接口。
- **API Key**：可选，以 `X-API-Key` 请求头发送；留空且 URL 未变时自动保留原密钥。
- **阈值 / 缓存天数**：风险分阈值 `0–100`（默认 `25`），缓存天数 `1–90`（默认 `7`）。

#### 4. 可选检查项开关 & 保存栏
- 可按项勾选开启/关闭 13 个可选检查项（关闭后显示 `已跳过`，绝不冒充通过）。
- 点击 **`恢复默认`** 加载出厂默认值，点击 **`保存设置并重新检查`** 持久化至 `config.json` 并立即生效。

## 四、常见场景速查（照着做不踩坑）

| 场景 | 操作步骤 |
| :--- | :--- |
| **Claude 仅走 TUN，同时保留系统代理给 Codex / 浏览器** | 1. 设置页开启 **WFP 严格模式**，保持 **WFP 允许本机回环** 为**关闭**。<br>2. 保持系统代理正常开启。<br>3. 先彻底关闭已有 Claude 进程，通过 Guardian 的 **「安全启动 Claude」** 打开即可。 |
| **换了不同国家的代理节点** | 切节点后打开 **「维护工具」→ 点击「重新适配出口地区」**，一键更新期望国家、时区与系统 Locale。 |
| **触发红灯「已阻断」无法启动 Claude** | 1. 先检查代理客户端与 TUN 网卡是否恢复在线。<br>2. 查看右侧「断网 / 阻断原因」，必要时点 **「维护工具 → 一键修复环境」**。<br>3. 点击底部 **「检查并解除阻断」**，全部硬检查通过后即可恢复安全启动。 |
| **把多个账号安全迁移到新电脑** | 1. 切到非目标槽位，在 **「多账号管理」** 选待导出槽位、设 8 位以上密码，点 **`导出 .csnap 快照`**。<br>2. 把 `.csnap` 复制到新电脑，选一个**空槽位**输入密码点 **`导入 .csnap 快照`**。 |
| **完整卸载并清理网络规则** | 管理员 PowerShell 执行 `.\install.ps1 -Uninstall`（自动清理 WFP、防火墙规则、计划任务并恢复时区；你的多账号存档与配置保留在 `%LOCALAPPDATA%\ClaudeDesktopGuardian`）。 |

## 五、命令行工具（CLI）速查

安装目录与发布目录中的 `ClaudeDesktopGuardian.Cli.exe` 支持脚本调用与无界面排查：

```powershell
# 环境巡检
.\ClaudeDesktopGuardian.Cli.exe check                          # 简要结果 (OK / FAIL)
.\ClaudeDesktopGuardian.Cli.exe checkdetail                    # 24 项逐行明细
.\ClaudeDesktopGuardian.Cli.exe check-item egress-ip           # 单项真复检

# 账号切换与加密快照（密码通过 stdin 传入）
.\ClaudeDesktopGuardian.Cli.exe status
.\ClaudeDesktopGuardian.Cli.exe switch B                       # 切换到槽位 B（可加 --no-launch）
echo 'YourStrongPass' | .\ClaudeDesktopGuardian.Cli.exe snapshot-export A .\slot-a.csnap
echo 'YourStrongPass' | .\ClaudeDesktopGuardian.Cli.exe snapshot-import .\slot-a.csnap B

# 区域 / 客户端 / TCP-only / 配置管理
.\ClaudeDesktopGuardian.Cli.exe set-region
.\ClaudeDesktopGuardian.Cli.exe get-client
.\ClaudeDesktopGuardian.Cli.exe set-client clash-verge
.\ClaudeDesktopGuardian.Cli.exe get-flclash-controller
.\ClaudeDesktopGuardian.Cli.exe set-flclash-controller auto
.\ClaudeDesktopGuardian.Cli.exe tcp-only-status
.\ClaudeDesktopGuardian.Cli.exe tcp-only-enable
.\ClaudeDesktopGuardian.Cli.exe tcp-only-disable
.\ClaudeDesktopGuardian.Cli.exe get-check-config
.\ClaudeDesktopGuardian.Cli.exe set-check-config '{\"allowOptionalFailures\":false}'

# 只读体检与隔离工具
.\ClaudeDesktopGuardian.Cli.exe rules-status
.\ClaudeDesktopGuardian.Cli.exe fingerprint
.\ClaudeDesktopGuardian.Cli.exe cli-info
.\ClaudeDesktopGuardian.Cli.exe open-safe https://browserleaks.com/webrtc
.\ClaudeDesktopGuardian.Cli.exe diagnose-proxy --proxy http://127.0.0.1:7897
.\ClaudeDesktopGuardian.Cli.exe export-diagnostics .\diagnostics.zip
```

> **Windows PowerShell 5.1 提示**：传递 JSON 字符串给 `set-check-config` 时，双引号需写成 `\"`（如上所示）；在 PowerShell 7+ 或 CMD 中可按对应 Shell 规则正常传参。
